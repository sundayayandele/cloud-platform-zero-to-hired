# Capstone 3 starter kit

Copy `docs/` into your platform repository and fill it in as you go. The brief is
[phases/03-platform-sre/capstone-3/README.md](../../phases/03-platform-sre/capstone-3/README.md).

| File | What it is |
| --- | --- |
| `docs/evidence-checklist.md` | Every item the mentors check, with a place for your evidence link |
| `docs/game-day.md` | Plan and write up a chaos experiment or game day |
| `docs/platform-handbook.md` | The handbook a new team reads to use your platform |

Reuse from the course's labs:

| You need | Start from |
| --- | --- |
| Argo CD, ApplicationSet, Rollouts with analysis | `labs/gitops/` |
| SLOs, error budget policy, incident process, postmortem template, chaos, Velero | `labs/sre/` |
| Golden path template, Crossplane, Kyverno, Conftest | `labs/platform/` |
| Trivy, Falco, audit logging, residency policy | `labs/security/` |
| OpenCost, the three-cloud cost model | `labs/finops/` |
| The triage assistant (optional) | `labs/aiops/triage/` |
